# 本地开发

当前应用以 `web/` 前端为主，真实 AI 请求统一调用同域 FYJIT Creative API，再由服务端 Worker 和 Relay 执行。

## 1. 启动前端

```bash
cd web
bun install
bun run dev
```

前端默认访问：

```text
http://localhost:3000
```

## 2. 连接 FYJIT

在 FYJIT 主站完成渠道和本站 Token 配置，并通过反向代理以 `/creative/` 提供本应用。前端不提供 API Key、Base URL、第三方提示词同步或 WebDAV 生产入口。

## 3. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改 FYJIT 合同：主要看 `contracts/creative-v1.json`、`web/src/services/api/creative.ts`
- 改文档站内容：主要看 `docs/content/docs/`
