# 功能介绍

本应用是 Infinite Canvas 的 FYJIT 派生前端，部署在 `/creative/`。FYJIT 主服务负责登录、权限、模型能力、本站 Token、估价、任务、Relay、消费审计、资产、提示词和画布持久化；浏览器只负责交互与可恢复的瞬时缓存。

## 创作工作台

- 生图工作台：文生图、参考图编辑、批量候选、部分成功、服务端历史、结果自动资产化和单项重试。
- 视频创作台：文生视频、图生视频、多模态参考、服务端异步轮询、关闭页面恢复、结果资产化，并可显式送入 FYJIT 影视制作项目。
- 模型、能力限制、推荐项、本站 Token 摘要和估价来自同域 Creative API，不按模型名称在浏览器猜测。
- Creative Intent 只携带短时意图和资产 ID，用于主站、角色工坊、工作台与影视制作之间跳转。

所有真实模型调用都经过 FYJIT Worker 和 Relay。前端不提供 API Key、Base URL、渠道编辑、浏览器直连脚本或 WebDAV 生产入口。

## 无限画布

- 服务端保存画布项目、节点、连线、视口和版本；更新使用乐观锁，冲突不会静默覆盖。
- 支持图片、文本、视频、音频、生成配置、分组和插件节点，以及拖拽缩放、连线、小地图、撤销重做、导入导出。
- 文本、图片和视频节点通过统一 Creative Job 生成，生成结果立即关联 FYJIT 资产 ID。
- 节点可以引用素材中心资产和提示词；已有服务端资产会复用 ID，不会先下载再重复上传。
- 自动保存会把瞬时 Blob/Data URL 转成用户私有服务端资产；持久化画布不以大型 Base64 作为权威数据。

## 素材中心

- 服务端统一管理图片、视频、音频、角色、文本、画布及其派生关系。
- 支持分页、搜索、类型与来源筛选、标签、收藏、编辑、上传、下载和软删除。
- 工作台、画布、角色工坊和影视制作共享同一套资产 API 与用户所有权校验。
- 私有内容通过同域受保护接口读取，不依赖上游临时 URL。

## 提示词库

- 支持搜索、分类、标签、收藏、创建、编辑、复制、删除、变量填写和不可变修订版本。
- 工作台和画布使用服务端提示词数据；生产浏览器不直接同步来源不明的第三方提示词正文或预览图。

## 画布助手与本地 Agent

- 画布助手可以读取选中节点和上游节点，生成文本或图片并把结果插回画布。
- 可选的本地 Canvas Agent 可连接用户机器上的 Codex / Claude Code，并通过 MCP 操作当前画布。本机登录态、文件权限和 Agent 凭据不会上传到 FYJIT。

## 插件

- 保留公开的节点插件 SDK 与受控插件加载机制。
- 插件调用 AI 时仍由宿主转交 Creative API；生产环境不会向插件暴露上游 Key。

## 当前边界

- 当前能力注册表未开放音频生成；音频可以作为资产和视频参考。
- 画布核心编辑以桌面端为主，移动端提供导航、查看和轻量操作，仍需持续完成全视口视觉回归。
- 真实模型、计费、内容审核与可用参数取决于 FYJIT 管理员配置和当前用户权限。
- 本地缓存不是跨设备数据源；跨设备恢复以服务端 Job、资产、提示词和画布记录为准。
