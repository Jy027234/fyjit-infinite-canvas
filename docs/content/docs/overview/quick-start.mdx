# 快速开始

本派生版本是 FYJIT 创作中心的独立前端，必须连接同域 FYJIT Creative API。单独启动静态页面可用于界面开发，但不能绕过 FYJIT Relay 发起真实生成。

## 生产部署

使用不可变 commit 构建镜像，并通过主站反向代理把 `/creative/*` 指向本容器、`/api/creative/*` 指向 FYJIT Go 服务。运行时必须设置与镜像完全对应的 `SOURCE_COMMIT` 和 `SOURCE_URL`。

## 本地启动

```bash
git clone <FYJIT 公开派生仓库 URL>
cd fyjit-infinite-canvas
cd web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

## Docker 启动

如果你需要基于当前源码构建镜像：

```bash
docker build --build-arg VITE_BASE=/creative/ -t fyjit-infinite-canvas .
docker run --rm -p 3001:3000 --env-file .env fyjit-infinite-canvas
```

## 首次使用建议

- 先在 FYJIT 主站完成登录、模型渠道和本站 Token 配置。
- 通过同域 `/creative/image` 进入本应用；启动时会调用 `/api/creative/bootstrap` 获取用户、功能开关、导航和能力版本。
- 在素材、提示词或画布页面写入数据后，换设备登录同一账号验证服务端同步。

## 说明

- 服务端数据是唯一权威来源，IndexedDB/本地存储只可作为瞬时缓存。
- 上游 API Key 和 Base URL 不进入浏览器；所有真实模型请求必须经 FYJIT Relay。
