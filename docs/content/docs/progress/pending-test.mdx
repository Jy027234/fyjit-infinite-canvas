# 待测试

## P1 工作台层级、费用确认与模板直达

- 生图和视频工作台应共享一致的页头、移动端记录/参数入口、字段标题、参数折叠区和底部提交区；390、768、1440、1920 宽度下主要生成按钮可见、键盘焦点连续，深浅主题的边框、背景、圆角和焦点样式一致。
- 生图、视频、素材和提示词卡的续作主操作应排在次要操作之前，删除保持危险操作样式并位于末尾；移动端按钮采用一致的双列布局且不溢出。系统模板“保存到我的提示词”、图片“加入参考图”和视频“送入影视制作”应显示为主操作。
- 修改模型、尺寸、数量或参考素材后，旧费用应立即隐藏并显示“正在核对”；新的服务端结果返回后，首屏只突出用途、模型、实际尺寸/数量和预计费用，Token、能力验证、参考限制及服务端说明仅在“查看校验详情”中展示。
- 已成功生成的图片和视频结果应明确显示“已保存到素材中心”，不再出现没有实际保存行为的“添加到资产”按钮；历史记录请求失败且无缓存时只显示错误与重试，不应同时显示“暂无生成记录”。
- 视频历史同时存在多个排队或运行任务时，只把最新任务作为当前可取消任务，其余任务仅在后台更新历史；点击“取消当前任务”不得取消较早任务，也不得因任一后台任务结束而错误切换前台运行状态。
- 生图批量任务和视频任务应按服务端状态显示“准备素材”“排队中”或“生成中 · N%”，页头与结果占位卡保持一致；进度更新不得伪装成错误文案，已完成任务不再显示运行状态。
- 提示词库及工作台提示词选择器首次加载应显示明确加载状态，请求失败时显示内联错误和重试且不误报空结果；筛选后的后台刷新可保留已有卡片。选择器内必填变量为空时不得应用，填写后正向和负向提示词中的同名变量都应替换。
- 打开 22 套系统模板详情，填写变量后点击“用于生图”，应通过一次性意图把最终正向和负向提示词带入生图工作台；必填变量为空时阻止跳转并标红字段。“保存到我的提示词”“复制最终提示词”和“用于生图”保持独立。
- 从生图工作台返回提示词库后，页码、每页数量、搜索、分类、类型、标签、来源、收藏筛选和列表滚动位置应恢复；会话结束后不要求跨会话保留。
- FYJIT Creative Theme 的 success、warning、info、neutral、chart、overview、skeleton、table 和乘法圆角变量应与主站基础主题一致，并可由 Tailwind 语义类使用；Ant Design 的 Button、Input、Select、Menu、Table、Modal 应在深浅主题下共享对应颜色、32/28/36 像素控件高度、焦点、字体、圆角和阴影，不得引入主站 console 专属的红色 primary 或 cyan ring 覆盖。
- 主站认证页、API Key 与渠道页的在线、错误、危险、复制成功和重试状态应跟随 success、destructive、warning 等语义变量；Console 不得覆盖全局 primary、ring 或 radius。创作中心的危险按钮、外部提示词来源提示及画布同步错误应在深浅主题下保持同一语义和可读对比度。
- 素材删除后应显示“已移入回收站”的持久反馈并可直接撤销；素材/提示词保存、导入和精修、画布导入、版本快照与恢复成功后应保留可关闭的结果说明。引用草稿恢复、跨工作台续作、提示词来源读取、项目列表及版本历史失败时应显示内联错误与就地重试，不得只依赖 Toast；清空、删除和版本恢复仍须经过结果明确的确认弹窗。

## P2 非首屏加载

- 打开主站 AI 对话但尚未显示源码或编辑消息时，不应请求 CodeMirror 运行时；悬停或聚焦“显示源码”“编辑”入口后应只预加载一次，点击后源码展示、行号、编辑、保存及快捷键保持可用。
- 首次打开画布项目时不应请求插件管理器、素材选择器或图片工具弹窗模块；悬停/聚焦节点插件、添加参考图或图片快捷工具后应预加载对应分包，点击后弹窗正常打开且关闭、确认与取消行为不变。生产构建中画布项目路由应维持约 238.84 kB（gzip 72.68 kB），不得回退到拆分前的 300.80 kB（gzip 90.76 kB）。
- 96 条素材、连续加载 200 条生成历史与 1,000 条 Agent 消息的独立 Chromium 三次测量中，两帧交互延迟中位数应保持在 30 毫秒内；当前无需虚拟列表，Agent 非流式历史继续使用 `content-visibility`，若真实用户指标后续接近 200 毫秒再重新评估。
- 配置 GA4 或百度统计时，LCP、INP、CLS、“工作台可输入”和“任务已接受”事件应只包含归一化页面、移动端/桌面端、版本、指标值及评级；带 `agentToken`、草稿或提示词查询参数进入页面后，统计载荷不得出现查询字符串、提示词、素材地址、账号标识或 Token。未配置统计时不得产生外部统计请求。
- 构建当前主站和固定提交的配套创作中心镜像后，执行 `scripts/creative-integrated-browser-smoke.ps1` 应通过 9 条跨应用用例：主页登录与共享会话、主题/语言/账号/退出、草稿经主站往返恢复、系统模板变量通过一次性意图带入生图、图片任务入库、视频关闭后恢复、角色素材经视频续作到 FilmGen，以及新用户模型发现、估价与真实消费；发布工作流中任一失败均应阻断三平台发布。
- 两端生产构建应自动执行体积预算。主站应输出主入口、初始 JS 总量、最大路由/异步 chunk 和初始 CSS，创作中心应输出初始 JS、最大路由 chunk 和初始 CSS；任一 raw 或 gzip 值超过 `bundle-budget.json` 后构建必须失败。提高预算或新增大依赖的 PR 应填写体积影响、拆包取舍和评审结论。

## 生图与视频工作台草稿及历史语义

- 生图与视频生成记录首屏应分别只请求一次 `/api/creative/jobs?page=1&page_size=20&include_assets=summary`，不再为当前页每个结果和参考素材追加独立详情请求；点击“加载更多”后按页追加且不重复已有记录，数量标签显示“已加载/总数”。
- 生图与视频历史应共享 TanStack Query 的 15 秒缓存、稳定 capability/page-size query key 和请求取消信号；页面切换或同页重复挂载不应立即重复请求，加载下一页后应合并并去重任务和素材摘要。
- 展开某条生图或视频历史后才应读取摘要中缺失的完整素材；同一素材详情应共享 5 分钟缓存、支持请求取消、失败自动重试和手动重试，再次打开同一记录不应重复请求。未展开记录时仍不得产生素材详情 N+1 请求。
- 生图和视频任务在创建、轮询、完成、失败或取消时，应只更新对应的历史记录和素材摘要；不应重新请求整页历史或失效整个素材查询域。新生成素材应直接加入符合当前类型、项目、来源、标签、时间和搜索条件的素材首屏缓存，已加载的后续分页不应被重排。
- 当前页素材已删除、无权限或摘要缺失时，对应预览应安全降级而不阻塞整页历史；新任务完成后的单条结果仍应正常展示，刷新历史后能够复用服务端摘要。
- 生图或视频任务已成功、但结果素材详情暂时读取失败时，应显示“任务已完成，结果详情加载失败”，不得显示为生成失败；点击“重试加载结果”只应再次读取已有素材详情，不得新增 `POST /api/creative/jobs` 请求或产生重复计费。
- 分别以两个账号进入生图和视频工作台，输入提示词、负向提示词、模型参数并选择不同项目，切换页面后返回应恢复各自对应项目的草稿；草稿只应包含提示词、必要参数和可读取的服务端 `assetId`，不应包含 `data URL`、`blob`、Token 或账号隐私。
- 从素材中心插入图片、视频或音频作为参考后离开页面，返回应尝试按 `assetId` 恢复；已删除或无权限的素材应被忽略并提示重新选择，本地临时上传素材不得伪装成可恢复草稿。
- 视频模型开放音频参考时，素材选择器应显示音频并可直接插入；单个音频不足 2 秒、超过 15 秒或累计超过 15 秒时应保留选择器并说明原因。素材中心音频点击“用于视频”后应恢复到参考音频区，画布插入音频应创建可继续连接的音频节点。
- 生成任务成功创建后刷新或离开页面，当前工作台草稿应按规则清理；估价失败、素材上传失败或任务未创建时应保留草稿。退出登录后重新登录同一账号不应恢复已清理草稿，其他账号草稿不受影响。
- 点击生成记录只能预览历史结果，当前未提交提示词、参考素材、项目和参数不得改变；点击“用于再次创作”后应先确认替换，再将历史参数填入草稿并按项目保存。
- 确认替换历史参数后，工作台应出现“撤销替换”入口；点击后应恢复替换前的提示词、项目、参数、服务端参考素材和结果预览。生图与视频生成记录不应再显示多选、全选、删除或删除确认入口，只保留新建与预览。

## 创作中心初始化与局部恢复

- 模型、能力和本站 Token 请求应与认证及模块权限初始化独立；其中任一可选请求失败时，素材中心和提示词库仍可打开并正常读取、编辑、保存。
- 首次进入素材中心或提示词库时不应请求无关的模型、能力或本站 Token 列表；进入生图、视频或画布工作台后，才按工作台需要加载对应资源，提示词 AI 精修应在用户点击精修时再加载文本模型和本站 Token。
- 生图、视频工作台在模型或 Token 请求失败时应显示局部错误说明；点击“重试加载”只重试失败资源，不应重复请求 bootstrap，也不应清空当前提示词、参考素材或其他页面状态。
- 在 React StrictMode 开发环境下刷新页面，`/bootstrap` 每次页面初始化只应请求一次；可选资源同一时间也不应产生重复请求。

## 素材与服务端提示词查询缓存

- 素材中心的分页、类型、来源、项目、目录、搜索、收藏、模型、标签、时间及回收站筛选应进入稳定 React Query key；只有搜索输入延迟 250ms，分页及其他筛选应立即生效，切换期间保留上一页内容。
- 素材上传、文本素材创建、编辑、收藏、删除、恢复及新建项目后，应只失效对应素材或项目查询域；素材选择器和画布侧栏重复打开相同查询时应在 30 秒内复用缓存。
- 服务端提示词列表的分页、搜索、分类、类型、标签、来源与收藏筛选应进入稳定 React Query key，并支持 AbortSignal 与 15 秒缓存；新建、编辑、导入、收藏、复制和删除后列表应更新。
- 生图、视频和画布的提示词选择器应复用服务端提示词缓存；关闭后再次打开相同查询时不应立即重复请求，系统目录模板仍保持只读且可填写变量或另存个人副本。
- 生图与视频现在共享工作台外壳、历史状态面板、成功结果卡外壳、编辑面板、结果面板和历史草稿提示；桌面折叠与移动抽屉应共享数量、错误、加载、空状态和加载更多逻辑，且保留各自的预览、下载、再次创作等操作；键盘焦点及深浅主题下应保持相同层级与操作语义。
- 后端导航返回 `/creative/image`、`/creative/video` 等部署路径时，创作中心桌面与移动导航应归一化为当前 Router basename 下的本地地址，不应产生 `/creative/creative/*` 双重前缀；未知或无效地址应回退到对应工具的稳定本地路由。
- 进入任意 `/canvas/:id` 画布项目后，左上角画布菜单应显示当前语言下的五个创作工具、标记“无限画布”为当前项，并遵守后端禁用项；从这里切换到生图、视频、素材或提示词时不应丢失 Router basename。
- 创作中心桌面和移动账户菜单应提供个人资料、钱包与退出登录；前两项使用 FYJIT 主站的普通文档链接，点击退出应先确认，取消不得请求 `/api/user/logout`，确认后才清理当前账号草稿并跳转登录页。画布项目页在移动端也应始终显示“返回 FYJIT”。
- 画布项目页在 390px 移动端应可通过紧凑头像打开个人资料、钱包、语言、主题与退出操作；主题变化同步更新根节点和共享 Cookie。当前画布未保存时，切换任何创作工具、返回 FYJIT、打开主站账户页或退出登录都必须先保存；保存失败并选择“继续编辑”后应留在原画布。
- 素材中心首次加载失败时应显示内联错误和“重试加载”，不得同时显示“没有找到素材”；已有列表的后台刷新失败时保留旧数据和同一重试入口。提示词选择卡正文与“使用”按钮应是两个独立控件，正文按钮可通过 Tab 聚焦并用 Enter/Space 选择一次。
- 从未登录的主站入口访问 `/creative/*`，完成密码、微信或注册后的登录流程时应保留 query/hash 并执行整页跳转，不得落入主站 SPA 404；外部 URL、协议相对 URL和含反斜线的恶意 `redirect` 必须回退 `/dashboard`。主站顶部“AI 创作”与侧栏、营销入口均应保持同页打开。
- 生图和视频历史状态应共享 CREATED/QUEUED、RUNNING、SUCCEEDED、PARTIAL_SUCCESS、MODERATION_REJECTED、FAILED、CANCELLED、EXPIRED 的显示映射；成功、处理中、部分成功、失败和取消分别使用 success、processing、warning、error 和 default 语义，时长、分辨率等非状态标签保持中性。
- 执行 `bun run theme:check` 应验证 43 个共享颜色 token、Tailwind 映射、Ant Design 生成适配器、合同版本及源 SHA-256；本地存在主站仓库或显式传入 `--source` 时，还应逐项比较规范化 JSON 的 light/dark 值，并在生成文件过期、缺失或漂移时失败。主站 `npm run theme:check` 与生产构建也应拒绝过期生成文件。

- 分别从本地上传参考图、参考视频和参考音频后提交生图、视频或画布任务，确认不会再出现 `Failed to fetch`；若刷新后本地素材文件确实丢失，应提示重新上传而不是显示浏览器原始错误。
- 在无限画布的图片/视频节点点击“添加参考图”，分别添加人物、背景和道具图片；在提示词任意位置输入 `@` 并选择缩略图，确认仅被引用的图片按提示词出现顺序随任务提交。未输入 `@` 时仍应提交全部已连接参考图。
- 使用无限画布视频节点分别验证 HappyHorse 图生视频和参考生视频：本地参考图不应再触发 `Failed to fetch`；参考数量与模型不兼容时应立即说明如何切换模型；任何素材读取或提交错误都必须退出“生成中”状态并显示具体原因。
- 选择 HappyHorse 视频模型，确认时长为 3–15 秒、步长 1 秒的滑杆，且只显示上游支持的 720p / 1080p。

- 创作导航与模型隔离：首页和创作中心顺序应统一为生图、视频、无限画布、素材中心、提示词库；进入生图或视频工作台时只能显示对应能力模型，旧配置中的跨类型模型不得回显。
- 生图模式：文生图可直接生成且不携带参考素材；切换到参考图编辑后必须选择参考图，模型不支持参考图时该模式应自动禁用并给出说明。
- 视频能力参数：HappyHorse t2v、i2v、r2v 应分别显示文生视频、单首帧图生视频和多参考图生视频能力；只展示服务端允许的 720/1080、比例和 3–15 秒时长，图生视频应提示比例继承首帧，素材选择后须明确点「插入已选素材」才加入任务。
- 素材插入定位：从素材中心向生图或视频工作台插入图片/视频后，弹窗应关闭、页面应滚动到对应参考区，并明确显示“首帧/主参考”或“运动参考”及提交用途，不得只显示成功提示而让用户找不到素材。
- 画布本地素材同步：上传本地图片、视频或音频并立即连接到生成节点时，自动保存应从浏览器持久存储上传素材；即使页面中的临时 Blob 地址失效，也不应持续出现 `Failed to fetch`，刷新后素材与连线应保留。
- 画布云保存闭环：新增或编辑文字、上传图片后，顶部状态应依次显示“未保存”“保存中”“已保存”；只有素材上传和画布更新都成功后才能显示“已保存”，点击状态可立即保存；保存未完成时刷新应触发浏览器离开提醒，切换主页、我的画布或新建画布应先完成保存；保存失败时顶部与警告条均可重试，成功后刷新图片、文字、连线和视口均应保留；仅刷新已保存画布不得生成无意义的新版本。
- 限流恢复：快速连续估价或提交任务触发 429 时，应显示“请求过于频繁”和建议等待秒数；正常操作频率下不应被通用高危接口限流误伤。
- 创作项目闭环：素材中心可新建项目并按项目筛选；文本、上传素材可选择项目；生图和视频工作台选择项目后，任务及最终结果素材应保留同一项目 ID；包含素材的项目不得误删。
- 文本素材说明：新建文本弹窗应说明其会作为提示词用于生图、视频和角色创作，也可保存脚本、对白或创作说明；保存后各“用于…”入口仍可正常带入下游工作台。
- 无限画布引用与停止：提示词输入区可通过 `@` 选择人物、背景、首帧等连接素材，首次粘贴富文本不应出现黑字；点击停止后应同时终止浏览器请求与 FYJIT 服务端任务，缩放或再次生成不能留下仍在运行的旧任务。

- FYJIT 子路径与容器：构建后访问 `/` 应跳转到 `/creative/`，直接刷新 `/creative/image`、`/creative/video`、`/creative/assets`、`/creative/prompts` 和 `/creative/canvas` 均不应 404；静态资源与插件清单应从 `/creative/` 加载，`/healthz` 应返回 200，运行时 `config.js` 应包含 Creative API、主站和精确源码元数据且禁止缓存。
- FYJIT 初始化：页面首次加载只请求一次同域 `/api/creative/bootstrap`，携带站点会话且不从查询字符串导入 API Key 或 Base URL；接口不可用时不得回退到浏览器直连模型。
- FYJIT 模型发现：bootstrap 完成后应只显示当前账号由服务端返回的文本、生图和视频模型，并优先选择每种能力的服务端推荐模型、无推荐时使用首个可用模型；生图和视频提交前应展示本站 Token、估价、归一化参数、参考素材上限、验证状态和风险提示，不支持的参考视频/音频或高级参数不得显示；浏览器状态、构建产物和界面均不应再包含上游 API Key、Base URL、自定义直连脚本或 WebDAV 配置，旧 `infinite-canvas:ai_config_store` 凭据缓存应在启动时清除。
- FYJIT 退出登录：桌面头像菜单和 H5 导航抽屉均应显示退出入口；成功退出后清除派生前端偏好与会话缓存并回到 FYJIT 登录页，服务端素材不得被删除。

- 画布节点缩放稳定性：选中任意节点并反复拖动四角缩放时，节点工具条应在缩放期间隐藏、松开后恢复，页面不应再出现 `Maximum update depth exceeded`。
- Agent MCP 初始化状态：首次进入空白对话或点击「新对话」后，无需先发送消息，对话区应立即显示 Codex 会话准备，并同时列出 `codex_apps`、`infinite-canvas`、`node_repl` 等全部 MCP 服务各自的启动、就绪或失败状态；初始化期间可输入并保留草稿，但发送按钮、上传和回车提交应禁用，全部完成后显示服务数量、恢复发送并复用同一个预热线程；右侧日志应记录同样的真实状态，`starting` 与 `ready` 归入信息且就绪显示绿色成功图标，只有 `failed` 归入错误、`cancelled` 归入警告，模型开始处理后不应残留初始化文案。
- Agent 模型设置：连接 Canvas Agent 后，输入框左下方应显示当前 Codex 模型与推理强度；模型列表应来自当前账号实际可用模型且不显示内部审查模型或重复项，切换模型后强度选项随模型能力更新且无空白选项，刷新页面后保留选择，发送任务时实际使用所选模型和强度；本地控制台与右侧「日志」应记录本轮使用的模型和推理强度。
- Agent 新对话响应：一轮对话完成后点击「新对话」，聊天内容应立即清空并进入空白对话，不出现等待或新建按钮卡顿；后台应立即创建线程并预热 MCP，多个标签页应同步进入空白对话，点击后立即发送也不得误发到上一条会话或重复创建线程。
- Agent 读取画布卡片：读取当前画布完成后，卡片应按非零类型显示文本、图片、配置、视频、音频、分组、其他节点及连线数量，例如「3 个文本、5 张图片、2 个配置、4 条连线」；空画布应显示「当前画布为空」，执行失败时仍应显示错误信息，刷新恢复历史后统计保持一致。
- Agent 首次发送响应：在空白新对话中输入内容并按回车后，输入框应立即清空、用户消息应立即出现在对话中，再显示「正在思考」；线程创建或发送失败时，原输入和附件应恢复；任务运行期间输入的新草稿不应在请求成功后被清空。
- Agent 动态工具信息：执行内置生图、查看图片、命令、文件修改或其他动态工具时，卡片标题应显示具体工具名称；执行失败时正文应显示真实错误原因，刷新并恢复历史对话后仍应保持一致，不再统一显示「工具操作已完成」。
- Agent 画布生图：重启 Canvas Agent 后，其自动生成的工作区 `AGENTS.md` 应同步为最新版指令（用户自行编写的其他 `AGENTS.md` 不应被覆盖）；输入“生成一张图片”时应调用 `canvas_generate_image`，通过当前画布节点创建并运行生成流程；只有明确输入“使用 Codex 内置生图/ImageGen 技能生成”时才允许调用内置能力，Codex App Server 返回的 `imageGeneration` 结果应显示在对话中并作为保持原比例的图片节点添加到当前画布；Agent 不应在没有生成结果时提前声称“已生成”。
- Agent 顶部栏：标题只显示垂直居中的「Agent」，连接、对话、历史、日志、新对话和收起操作应位于同一行；面板较窄时标签仍可横向滚动且操作不应错位。
- Agent 面板按需加载：首次进入生图、视频、素材或提示词页面时不应请求 Agent 对话重模块；在画布顶栏悬停、聚焦或点击 Agent 入口后才允许出现对应分包请求，面板打开期间应先显示不改变右侧布局宽度的轻量占位，随后正常显示连接、对话、历史和日志；收起动画、宽度拖拽及带 `agentUrl`/`agentToken` 的画布路由自动连接均应保持可用。
- Agent Markdown 样式：右侧 Agent 回复中的代码块应为横向占满消息区域、无语言标题和无双层边框的紧凑代码条，单行内容不应保留纵向大面积空白，复制操作仅在悬停时弱化显示；行内代码、链接在浅色和深色主题下应清晰；点击外部链接后应显示中文紧凑确认弹窗，长路径能够正常换行且复制、继续打开和关闭操作可用；点击 `/Users/`、`/home/` 等本地绝对文件路径时应改为提示在系统文件管理器中定位，支持复制路径，且浏览器地址不应跳转为 localhost 文件路径。
- Agent 工具确认模式：右侧面板标题栏不应再显示「工具确认」开关；对话输入框左下方应显示确认模式选择，默认选中「自动确认」，画布写入工具应直接执行；切换为「手动确认」后，画布写入工具应在对话中展示等待确认卡片，并支持批准或拒绝。
- Canvas Agent Codex 升级：启动 Canvas Agent 后应输出 Canvas Agent、内置 Codex 和本机 Codex 版本，实际运行的内置 Codex 应为 0.146.0；内置与本机版本不一致、未安装本机 Codex，或 npm 存在更新版本时应显示对应升级提醒，npm 检查失败不应阻止服务启动；Agent 应能正常连接 Codex、创建或恢复会话、发送消息并调用画布工具，运行中停止任务应只中断当前 turn，随后无需重启 Agent 即可继续发送新任务。
- Canvas Agent Debug：普通启动应通过公共 logger 输出 Info、Warn 和 Error 日志；使用 `npx -y @basketikun/canvas-agent --debug` 启动后还应输出 Debug 日志并显示日志文件路径，终端统一采用“`YYYY-MM-DD HH:mm:ss` 级别 消息 详情”的纯文本单行格式，`~/.infinite-canvas/logs/` 下应按启动日期生成相同格式的 `canvas-agent-YYYY-MM-DD.log`，同一天多次启动应追加到同一文件；日志中不应出现连接 token 或图片 Data URL 原文。
- Canvas Agent Codex 日志：Codex app-server 输出带颜色或样式控制符及 UTC 时间的 stderr 时，本地日志和网页诊断日志应只显示一份 `YYYY-MM-DD HH:mm:ss` 本地时间和干净文本，不应出现重复 ISO 时间或 `[2m`、`[31m` 等 ANSI 转义内容。
- Agent HTTP 诊断日志：网页发送一条普通消息后，本地 Debug 日志不应重复输出 `/health`、`/canvas/state`、`/canvas/activate` 成功请求、流式增量或完整会话响应，只保留 HTTP 请求与 Codex 生命周期摘要；右侧「日志」应以单行时间线展示发送、开始、回复、工具、完成用量和错误，不再输出 userMessage started/completed、流式摘要、重复 threadId 或大段原始 JSON。
- Agent 排查日志：右侧「日志」中的排查视图应显示连接摘要，并可按错误、警告和信息筛选；向下查看日志时仅列表内部滚动，标题、连接状态、筛选数量和操作按钮保持固定；连续相同事件应折叠计数，单条日志可展开查看完整详情；原始 JSON、复制全部、复制最近错误和清空功能应继续可用，浅色与深色主题下均应清晰。
- Agent 排查日志顺序与跟随：日志应按时间从旧到新排列，进入日志或切换筛选时定位到最新事件；停留底部时自动跟随新日志，展开最后一条后应继续停留在完整详情底部，向上浏览后暂停跟随并显示与对话区视觉高度一致的居中圆形向下箭头，新日志数量只在悬浮提示中显示；列表底部不应出现额外留白，点击按钮后回到底部并恢复跟随。
- Agent 对话统计：用户消息应右对齐并使用透明无气泡的简洁排版，用户和 Codex 两侧均不显示人物头像，消息下方均不显示时间或 Token 信息；输入框上方应居中展示最新一次模型调用的输入、缓存、输出 Token 用量，不显示会话累计值，数值更新时应从旧值平滑滚动到新值而非突然跳变，新建、切换或删除当前会话后应清空旧统计。
- Agent 回复实时显示：在右侧 Agent 发送消息后，用户消息下方应立即出现“正在思考...”，任务运行期间不应闪退；工具完成后应显示 Codex 正在继续处理及已等待时长，等待超过 30 秒时提示可继续等待或停止本轮；Codex 的回复应在当前对话中持续显示，实时事件缺失时也应在任务完成后自动同步完整内容，无需切换到历史或日志再返回对话。模型繁忙等任务失败时应立即结束等待状态，在对话中显示中文错误原因和重试建议，诊断日志不应再把失败轮次记为“处理完成”，刷新历史后错误仍应保留。新建尚未发送首条消息的空会话不应反复出现历史读取失败。
- Agent 对话实时与历史一致性：运行包含思考、命令及画布工具的较长任务，在执行中刷新发起页面或打开第二个页面时，已出现的用户消息、思考过程、工具卡和回复前缀均应保留并继续更新；同一思考或工具只显示一张卡片，任务结束及再次刷新后内容、顺序和状态应一致。切换页面焦点不能改变本轮画布工具目标，发起页面断开后不得把图片或写操作转交其他画布，使用相同页面身份重连后才能继续处理。
- Agent 流式交互性能：发送长回复时文字应连续平滑出现，输入框、滚动和画布操作不应随回复变长而明显卡顿；长历史会话中只有当前流式消息持续更新，屏幕外消息不应造成明显布局压力；任务完成后应通过 SSE 自动同步完整历史，不再持续请求 `/health` 轮询状态。
- Agent 过程时间线：新建 Agent 对话后 Codex 应生成可读思考摘要，并在运行时依次显示中文的思考摘要、执行计划、命令执行、网页搜索、文件修改和画布工具活动；思考摘要的图标、标题和箭头应稳定保持在同一行，默认收起且无边框，点击箭头后才展开 Codex 实际返回的具体摘要，其中 Markdown 强调、列表和代码应正确渲染而非显示原始符号，多行代码块和文本流程图应保留原始换行并允许横向滚动，完成事件不应再用「已完成分析」覆盖已经收到的摘要；同一轮连续命令应合并为显示数量的无边框折叠行，折叠时不显示命令预览，单条展开后直接显示详情，多条展开后可逐条查看工作目录、耗时、退出状态和运行输出；其他工具调用继续使用紧凑卡片排版，状态图标、标题和状态文字保持在同一行；结构化任务进度不应混在对话时间线中，而应独立放在对话区下方、Token 统计上方，支持展开和折叠，并逐项实时更新「待处理」「进行中」「已完成」状态；新任务生成时默认展开，任务结束后保留最新结果，同一计划更新不应生成重复内容；文件详情展示文件路径与新增/修改/删除动作，工具详情不应出现请求 ID、英文工具名或原始 JSON；一轮对话结束自动同步历史以及刷新页面后从历史中 resume 对话时，思考摘要、命令和工具过程记录仍应完整保留并保持相同展示。
- Agent 权限控制：输入框可选择「请求批准」「自动审查」「完全访问」；请求批准模式下，Codex 编辑工作区外文件、执行受限命令或访问网络时应在对话中显示审批卡片，支持拒绝、允许一次和本会话允许，并能依次处理多个并发请求；提交决定后卡片应保持禁用等待，只有 Codex 确认处理后才移除；等待审批时刷新页面，未处理的审批卡应自动恢复且不能让任务永久卡住；自动审查模式应仅将需要用户决定的风险操作送入审批；完全访问必须先显示风险确认，启用后可访问网络和本机文件且不再请求审批；选择应在刷新后保留。
- Agent 历史记录：点击记录卡片应直接进入对应对话，不再显示「进入」按钮；可勾选单条或全选多条记录并批量删除，删除当前对话后聊天内容应清空。
- Agent 默认新对话：每次进入任一画布并连接 Agent 后，对话区应保持空白且不自动恢复上一次会话，并在后台创建新线程、预热 MCP；需要继续旧对话时可在「历史」中主动选择恢复。
- Agent 当前画布优先：在已打开某个画布时要求 Agent 创建、修改、整理或生成内容，Agent 应直接读取并操作当前画布，不应先调用 `canvas_list_projects` 或使用 `site_navigate` 重复进入画布；只有明确要求查看或切换其他画布时才允许查询画布列表并导航。
- Agent 图片消息：发送一张或多张图片附件后，图片应紧跟用户文字并在消息右侧显示为约 40px 的紧凑缩略图，不再撑大消息区域，单击缩略图应打开大图预览，打开或关闭预览不应改变消息间距或产生额外空行；任务运行中、完成同步历史、切换页面及重新进入历史对话后都应显示浏览器本地保存的图片缩略图，不应消失或把 attachmentId、附件使用说明等内部上下文回显到用户消息中；删除历史会话后应同步清理对应缩略图。
- 画布文本复制：在 Agent 对话或节点信息详情中用鼠标选中文字后，按 `Ctrl/Cmd + C` 应复制所选文本，不应触发画布节点复制；未选中文字且焦点位于画布时，原有节点复制快捷键应保持可用。
- Agent 工作目录指令：`canvas-agent/agent-instructions.md` 应作为独立维护源；重启 Canvas Agent 后，当前工作目录应自动生成 `AGENTS.md`；新建对话发送消息时，Codex 日志中的用户消息只包含本轮请求和必要的附件上下文，不再重复整段 Infinite Canvas 前置提示词，画布及工作台工具仍可正常调用。
- 画布文本设置：文本节点和生成配置节点切换到文本模式后应显示推理强度设置，可选择自动、低、中、高、极高；选择自动时默认 OpenAI Responses 请求不应携带 `reasoning`，选择其他档位时应携带所选强度，刷新画布后节点设置应保留；文本模型自定义调用脚本应能读取 `reasoningEffort`，OpenAI 模板应按自动或指定档位正确组装请求。
- 生图工作台参考图：将一张或多张图片拖入参考图区域后应直接上传并显示缩略图；拖入非图片文件应忽略，拖动过程中区域应显示高亮提示，放下文件不应导致浏览器打开或替换当前页面。
- 视频创作台参考资产：将图片、MP4/MOV 视频或 MP3/WAV 音频拖入任一参考资产区域后，应按文件类型自动上传到对应列表；当前拖入区域应显示高亮提示，原有数量、大小、时长和格式限制应继续生效。
- 画布组装提示词：输入或连接超长提示词后，浮层正文高度不应继续撑大，内容应可在正文区域内滚动查看和编辑，标题及关闭按钮保持可见。
- 画布节点提示词：图片等节点下方的提示词超过输入区域高度后，鼠标悬停在输入区域内滚动应查看提示词内容，不应缩放画布。
- 画布节点提示词回显：单图或多图生成完成后，切换选择生成结果的根节点及任一子节点，下方输入区域都应继续显示生成时的提示词；切换到其他节点再选回来后也不应清空。
- 画布生成配置：连接文本节点后连续点击生成（包含失败重试），组装提示词不应重复追加上游文本；在生图、文本、视频、音频之间切换时，实际请求应始终使用当前面板展示的对应类型模型。
- 画布左侧元素列表：点击元素整行应平滑定位并选中对应节点；有内容的图片元素应显示预览按钮，点击后打开大图弹窗且不触发画布定位。
- 图片编辑弹窗：遮罩、切图和裁剪连续滚轮缩放时，图片与遮罩应保持同步且不再闪烁、短暂消失或跳动；遮罩画笔圆心应始终固定在鼠标位置，仅直径随缩放变化，缩放后仍可准确涂抹、拖动切分线和调整裁剪框。
- 提示词中心布局：页面标题及提示词总数应居中；连续输入搜索文字时应在停止输入约 300ms 后再查询；桌面端分类与标签应在左侧独立滚动，右侧搜索框下直接展示提示词卡片；标签数量较多时不能继续向下挤压提示词，窄屏下应恢复上下排列且内容不溢出；不再显示「我的提示词」Tab，收藏提示词应直接加入我的资产。
- 提示词详情弹窗：封面和参考图应固定显示在上方，复制及加入资产操作栏固定在底部，只有中间的标签、描述及提示词内容区域可以滚动；弹窗宽高应受视口限制且不超出屏幕。
- 提示词来源：6 个内置来源应从 Image Prompts 统一仓库读取，更新后数量依次为 323、494、53、76、126、129；提示词仍按 6 个来源分组并可独立启用，来源内可继续按 `tags` 筛选。添加标准 JSON URL 后应能查看内容，填写非数组 JSON 或不可访问地址时应显示失败，并继续保留该来源上一次成功缓存的内容。
- 提示词来源界面：来源应以卡片列表展示，启用开关位于左侧，数量、同步状态和上次成功时间作为次级信息显示，查看、拉取及自定义来源编辑/删除操作使用带文字按钮；底部定时拉取区域应保持独立边框布局。
- 画布提示词库：不应再显示「我的提示词」分组；不展开任何公共来源直接搜索其中的提示词，匹配项应自动显示；点击「插入画布」后应创建正文正确且标题保持为提示词标题的文本节点。
- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；非运行状态关闭当前页面后应回退到最近聚焦且仍连接的页面，运行中关闭发起页面则不得把操作转交其他画布，只有同一页面身份重连后才能继续；其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Codex 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Codex 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Codex 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
- 本地 Agent 图片附件落画布：在右侧 Agent 上传参考图并要求基于商品信息创建生图流程，附件应创建为保持原比例的真实图片节点，分析提示词应创建为文本节点，二者都应连接到生成配置节点；刷新页面后参考图仍可显示并参与生成。任务中途切换到其他标签页时，附件只能写入发起任务的标签页；若发起标签页关闭，附件读取应失败且不能落入其他画布。
- Agent 对话滚动：从历史或日志切回对话、恢复其他会话时应自动定位到最新消息；手动向上浏览后应显示与日志完全相同尺寸、位置和样式的居中圆形向下箭头，新消息不强制打断阅读，对话底部不应出现额外留白，点击按钮后平滑回到底部并继续跟随新消息。
- Agent 消息区分：用户消息应在右侧使用透明无气泡排版，AI 回复应在左侧使用无头像的开放式 Markdown 排版；长文本、多张附件、错误消息及浅色/深色主题下均应清晰且不溢出。
- Agent 命令记录：命令执行中应显示运行状态；完成后，同一轮相邻命令应合并为「已执行 N 条命令」折叠行且默认不显示原始命令，单条展开后直接显示完整详情，多条展开后可分别查看命令、输出和退出状态；对话结束或刷新后分组与记录不应消失。
